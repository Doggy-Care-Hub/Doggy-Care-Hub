## Activities Completed

1. Accessed Cloud Firestore through Firebase Console.

6. Selected Production Mode for initial database security.

## Database Purpose

Cloud Firestore will be used to store application data, including:

- User Profiles
- Dog Profiles
- Dog Breed Information
- Vaccination Records
- Vaccination Guidelines
- Nutrition Information
- Health Records
- Preventive Care Information
- Reminders

## Security Considerations

Production Mode was selected to provide an initially restricted
database access configuration.

Firestore Security Rules will be configured to protect user
data and restrict unauthorized access.
